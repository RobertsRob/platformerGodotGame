# About this game
This is a Godot 2D platformer game, where you as a robot should complete three levels. You can do levels in any order you like, but I recommend to do 1 -> 2 -> 3 to train on easier levels first. Third level is really hard but it IS possible to complete. 

You can play it here: [https://studiorst.itch.io/hard-3-level-platformer](https://studiorst.itch.io/hard-3-level-platformer)

## Game mechanics
You as a robot can move and jump, and there are spikes that resetyou to the beginning of the level. Your goal is to reach green-ish portal and go through it to return to level choice. Portal is oftenly located at the right side of the level.

## Controlls
- Move left (A; Arrow Left)
- Move right (D; Arrow Right)
- Jump (W; Space; Arrow Up)
